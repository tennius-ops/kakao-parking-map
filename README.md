# 🚗 깜빡 방지! 내 주차 & 위치 찰칵 지도 (Kakao Map & PlayMCP)

카카오맵 API와 PlayMCP를 활용한 시니어 친화적 반응형 주차 위치 저장 웹앱입니다.

## ✨ 주요 기능
- 📍 **원터치 주차 위치 저장**: 내 현재 위치(GPS)를 지도에 커다란 깃발로 표시하고 로컬 저장소에 저장
- 💬 **카카오톡 공유/전송**: 저장된 주차 위치를 카카오톡으로 내 채팅방이나 가족에게 전송
- 🚶 **원터치 길찾기**: 카카오맵 길찾기로 연결되어 내 차가 있는 곳까지 도보/차량 길안내
- 📱 **반응형 & 시니어 친화적 UI**: 큰 글씨, 고대비 색상, 직관적인 대형 버튼 적용

## 🛠️ 기술 스택
- HTML5 / CSS3 / JavaScript (Vanilla)
- Kakao Maps API SDK
- Kakao Javascript SDK
